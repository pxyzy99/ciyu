# 词屿四级 · 手机版

这是独立的四级手机端版本，放在桌面上，和六级版分开。直接双击 `index.html` 打开即可。

手机版采用单列布局、底部导航和应用式内滚动；底部导航独立占位，不会盖住正文。短屏手机会自动收起首页的装饰词卡，保证正文、按钮和选项完整可见。

进入背词/选择题时，页面会切成全屏答题：收起顶部栏和底部导航，把题干与四个选项压缩到一屏内；退出后回到进入前的位置，不会每次都跳回页面顶部。

一个安静的四级背词空间。所有数据都在本地运行，不需要联网。

## 词库

- 按 8 张图片的 56 列逐列放大校对，共 **1398** 个不重复词条。
- 8 张图合计抄录 1399 个位置；`aboard` 在第 2、7 张各出现一次，已合并为一个词条。
- 保留书中 `enrol(l)`、`organize/-ise`、`mo(u)ld` 等变体写法；音标和释义按标准词头匹配。
- 释义包含中文义项与英文释义，参考 ECDICT 数据整理；每条中文释义都带 `n. / v. / adj. / adv.` 等词性标签。

## 功能

- **今日学习**：每日目标可选 30 词、50 词或自定义（1–200 词）；默认混合练习。
- **多种背词形式**：保留「卡片回想」，并新增「英译中四选一」「中译英四选一」「拼写挑战」。可在今日计划里切换单一形式或混合练习。
- **词汇查询**：全库搜索英文或中文释义，支持词性、学习状态筛选。
- **学习数据**：已遇见、已相熟、常想起、未见面的词；展示熟悉的光谱、练习形式偏好和最近翻过的词，不记录打卡、连续天数或时间进度。
- **易错本**：自动收集「不认识 / 有点模糊」的词，按错误次数排序，可整组重练或单独重练。
- **乱序学习**：词库默认随机乱序，也可切换 A–Z、最易错、最近学习。
- **氛围细节**：全站一层稀疏的下坠颗粒；英译中 / 中译英的四个选项各有不同节奏的漂浮微粒。系统开启「减少动态效果」时会自动静止。

学习记录保存在浏览器的 `localStorage`（键名 `ciyu.study.cet4.v1`），不会和六级版共用进度。清除该站点的本地数据即可重置进度。

快捷键：`Ctrl/Cmd + K` 搜索；卡片页 `Space` 翻开、`1 / 2 / 3` 选择熟悉度；选择题 `A / B / C / D` 作答；拼写题 `Enter` 检查；`Esc` 结束本组。
